## 👨‍💻 Sobre mí

Construyo software que corre solo, de punta a punta:

- **Backends** con Python (FastAPI, Flask) y Java (Spring Boot): APIs SOA, autenticación OAuth2 y monitoreo.
- **Frontends** con Vue.js y Vuetify: dashboards, tiendas web y landing pages.
- **Apps Android** nativas con Kotlin y Jetpack Compose (MVVM, Room, Hilt).
- **Firmware** para ESP32 con FreeRTOS, sistemas en tiempo real y MicroPython.
- **Visión por computadora**: detección de objetos (YOLO), reconocimiento facial (DeepFace) y tracking óptico sub-píxel.
- **Blockchain**: contratos inteligentes en Solidity.
- **DevOps**: Docker, Nginx, Grafana, PostgreSQL y diseño digital en SystemVerilog.

Busco mi primera experiencia profesional: **open to internships** 🚀
